# basics

No database needed. These examples show core token creation and verification.

| File | What it shows |
|------|--------------|
| `all_methods_demo.py` | A quick tour of every single TempID method in one place |
| `stateless_token.py` | Create, verify, and check remaining time |
| `encrypted_payload.py` | Hide a dict inside a token and read it back |

**Run:**
```bash
pip install tempid
python stateless_token.py
```
